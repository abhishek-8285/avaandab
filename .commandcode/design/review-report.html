Findings

1. BLOCKER — Missing Datastar fragment template

internal/handlers/bookings.go:80 renders booking_list_table.html for AJAX/Datastar requests. That template file does not exist on disk — any table refresh will crash with a 500.

2. BLOCKER — "Complete" action missing from web UI

The BookingHandlers struct has completeUC wired but Routes() does not register a /complete route. The REST API supports POST /api/v1/bookings/{id}/complete but the web form has no path to complete a confirmed booking.

3. CRITICAL — External CSS/JS dependencies

Layout loads cdn.tailwindcss.com (dev-only CDN build, 300KB+ runtime compilation) and Google Material Icons from an external domain. No offline fallback.

4. HIGH — Generic color palette

Uses Tailwind defaults exclusively: bg-gray-50, blue-600 buttons, red-600/green-600 badges. No brand hue, no tinted neutrals — indistinguishable from generic SaaS.

5. MEDIUM — No dark mode

Layout hardcodes light-mode colors with no dark: variants or prefers-color-scheme support.

6. LOW — No SEO meta tags

layout.html has no <meta name="description"> beyond {{.Title}} - MVTMS.
